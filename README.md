# 현장명판 — 무료 구성 MVP

기본 배포는 **Cloudflare Pages + Pages Functions + Supabase Free**입니다. 별도 유료 Python 서버 없이 로그인, 사진별 정보 확인, 명판 합성, 다운로드를 구현합니다. 화면과 명판은 한국어입니다.

Cloudflare Pages와 전용 Supabase에 배포하여 사용자 로그인을 확인했습니다. 참고 사진 OCR 초안·검수 화면과 실제 비전 API 연결 코드를 추가했습니다. 검수 참고 사진 없이도 분석할 수 있으며 같은 폴더 대상 기기 정보를 활용합니다. 서버 API 키 등록·활성화·재배포가 필요하고 전체 시험 호출은 최대 100회로 제한합니다. **실제 외부 비전 API 호출·추천 정확도 평가는 아직 수행하지 않았습니다.** 서버 자동 삭제 예약과 실제 시험 파일 삭제를 확인했습니다. 모바일 실기기·A4 인쇄 검수는 남아 있습니다. [전체 점검 기록](docs/AUDIT_2026-10-17.md)을 참고하세요. [AI 설정 및 검수 안내](docs/AI_SETUP.md)를 참고하세요.

## 무료 MVP 범위

- 관리자/작업자 로그인·로그아웃, HttpOnly 세션, 기기별 작업 접근 권한
- 사진·하위 폴더 ZIP 순차 처리, 원본 경로/확장자 기록, 중복 표시
- 서버 PostgreSQL에 상태 저장, 비공개 Storage에 작업용 사본과 결과 저장
- EXIF 적용, 회전 수정, 자르지 않는 4:3 출력, 최대 1280×960 JPEG 품질 85%, 작은 사진 확대 안 함
- 제공 샘플에서 측정한 5행 2열 명판, 한글 글꼴 자체 포함, 오른쪽/아래 여백 0
- 기본 공사명 고정, 관리자 추가 공사명 목록 및 작업별 다른 공사명 직접 입력
- 사진별 수동 확정 및 PMA 혼동 작업 직접 선택 강제
- 개별/전체/날짜별 다운로드, ZIP은 약 24MiB 단위로 분할
- 저장 완료 확인 후 파일 삭제, 24시간 만료 접근 차단, 실제 운영 서버의 15분 정리 예약 및 관리자 실행 상태 표시

무료 한도 때문에 **작업당 50장, ZIP 90MiB, 압축 해제 150MiB, 사진당 8MiB·2천만 픽셀**로 제한합니다. 서버 사진 보관 예약 합계는 700MiB입니다. 모바일 메모리를 아끼도록 사진을 한 장씩 처리합니다. 서버에 원본 대신 최대 긴 변 1280px 작업용 사본을 저장하며, 원본은 사용자 기기에 남습니다.

**브라우저를 닫으면 업로드·명판 합성이 멈춥니다.** 이미 전송한 사진과 생성 완료한 결과는 복구하고 나머지를 이어서 생성합니다. 원본 ZIP 전송을 자동으로 이어받지는 않습니다. 월간 1,000장 비동기 서버 처리와 실제 정확도 평가는 미구현입니다. OCR 검수와 저수준 픽셀 특징 기반 참고 검색·선택적 비전 API 연결을 추가했으며 API 키·활성화·검수된 사진이 있어야 추천을 요청할 수 있습니다. 기존 Python 버전의 선택적 AI 연결과 이 무료 API를 혼동하지 마세요.

## 배포

[무료 구성 설정 안내](docs/FREE_SETUP.md)를 순서대로 진행합니다. Supabase와 Cloudflare 무료 계정이 필요합니다. Free 플랜을 유지하고 유료 업그레이드를 선택하지 않습니다. 무료 전송량·저장량·비활성 프로젝트 일시 중지 정책에 영향을 받으므로 항상 무제한 무료 운영을 보장하지 않습니다.

GitHub 저장소에서 **main → Code → Download ZIP**으로 소스를 받습니다. `.env`, 비밀 키, 사진, `node_modules`는 포함하지 않습니다.

## 빌드 및 검사

Node.js 22 이상:

```sh
npm ci
npm run build
npm run test:free
npm run test:frontend
```

`dist`가 Pages 출력 폴더입니다. Functions는 저장소의 `functions`에서 자동 탐색합니다. 정적 파일만 올려서는 API가 실행되지 않습니다. `npm run test:browser`는 Chromium 설치가 필요하며 `CHROMIUM_PATH`로 실행 파일을 지정할 수 있습니다. 무료 API 테스트는 실제 PostgreSQL 호환 PGlite SQL을 실행하지만 외부 Auth/Storage는 테스트 대체 서버입니다. 브라우저 검사는 실제 Chromium에서 합성/글꼴/ZIP을 검증하며 실제 클라우드 배포 검증과는 구별합니다.

기존 Python 로컬 버전 실행은 [기존 실행 안내](docs/LEGACY_README.md)를 참고합니다. `npm start`는 이 로컬 Python 버전입니다. 기존 유료 서버 배포 자료는 기본 무료 배포와 별개이며 자동으로 서비스를 만들지 않습니다.

## 구조와 보안

`static/`: 한국어 UI·Canvas·ZIP / `cloudflare/`: 서버 전용 인증·저장 API / `functions/api/`: Pages 라우팅 / `shared/`: 검증 규칙 / `supabase/migrations/`: 테이블·권한·비공개 버킷 / `supabase/functions/`: 삭제 작업 / `tests/`: 회귀 검사.

Auth 사용자 UUID와 서버 환경의 역할 매핑으로 권한을 결정합니다. 같은 공용 계정이어도 기기 쿠키와 작업별 HMAC 권한이 달라 다른 기기 작업에 접근할 수 없습니다. 브라우저 데이터 삭제 시 복구가 제한됩니다. 관리자 비밀번호 변경/세션 무효화는 앱 세션에 즉시 적용합니다. 새 프로젝트에서 사용하고 다른 앱과 관리자 키를 공유하지 마세요.

서비스 역할 키는 Functions 서버 환경에만 저장합니다. 테이블과 RPC는 anon/authenticated 접근을 차단하며 서비스 역할이 검증된 API를 통해서만 호출합니다. 사진 삭제 성공 후에만 저장 예약 기록을 제거합니다. 삭제 장애 때는 재시도하며, 실제 버킷에 파일이 남지 않는지 운영 점검이 필요합니다.

표 비율 측정 근거는 [샘플 검토](docs/sample-review.md)에 있습니다. 원본 글꼴과 모든 샘플 디자인을 완벽히 재현한 상태는 아니며 A4 6장 인쇄 가독성은 실물 출력 검수가 남아 있습니다.
