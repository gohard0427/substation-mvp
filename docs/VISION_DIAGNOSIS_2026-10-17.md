# 동작특성시험 인식 문제 점검

## 확인한 사실

- DB에는 동작특성 시험 OCR 항목이 80개 있었지만, 처음 실제 검색에 사용할 수 있는 검수 완료 참고 사진은 1개뿐이었다.
- 저장된 실제 추천 20건은 모두 참고 사진 대량 등록 이전 결과였다. 이번 점검 중 새로운 유료 추론은 실행하지 않았다.
- 실제 응답에는 여러 채널·리드선·내장 프린터를 가진 계측 장면을 저항 또는 PMA 전압 측정으로 추천한 사례가 있었다. 기존 프롬프트가 PMA 예외를 모든 사진에 명시하고, 모델의 구분 그룹 ID를 설비 타입 일치 없이 받아들인 문제도 확인했다.
- 기존 분석 사본은 우하단을 일률적으로 넓게 가려 계측기 단서 일부를 함께 가릴 수 있었다.

## 수정

- 12개 작업 폴더에서 동작특성 시험 사진과 원본 명판을 각각 화면으로 대조해 참고 사례를 1개에서 13개로 늘렸다. 전체 검수 완료 참고 사진은 24개에서 36개가 됐다. 평가용 폴더는 추가 검수 검색 자료에 포함하지 않았다.
- 신규 사진을 먼저 관찰하고, 타이밍 채널·연결 구성·시험 기록 등 여러 단서를 검수 사례와 비교하도록 안내했다. 프린터나 브랜드 하나로 시험을 단정하지 않으며, 관찰 근거가 없으면 작업을 확정하지 않는다.
- 일반 계측기 사진을 PMA로 임의 분류하라는 반복 안내를 제거했다. 모델이 구분 그룹 ID를 반환해도 설비 타입이 맞지 않으면 적용하지 않는다. 실제 PMA 타입과 해당 측정 장면의 필수 선택은 유지한다.
- 색상·공간 특징 검색의 상위 참고 사례는 서로 다른 표준 작업을 최대 3개 선택해, 한 작업이 사례를 모두 차지하지 않게 했다. 여전히 저수준 이미지 특징 검색이며 의미적 이미지 임베딩 검색이 아니다.
- 제공 자료에서 측정한 두 명판 프로필의 흰 배경·행 구분선이 확인되면 그 영역을 가린다. 확인할 수 없으면 기존의 보수적인 가림 범위를 유지한다. 원본과 출력 사진에는 이 분석용 가림을 적용하지 않는다.
- 추론 안내 버전을 v3으로 바꾸고 서버 캐시 키에 반영했다. 이전 버전 추천은 화면에서 재분석이 필요함을 표시한다. 사용자가 확정한 사진은 자동 재분석하지 않는다.
- GPT-5 계열의 reasoning effort를 low로, 출력 상한을 4,000토큰으로 조정했다. 누적 시험 최대 100회는 유지한다.

## 검증 범위

실제 PGlite/모의 공급자 테스트로 서로 다른 작업의 참고 선택, PMA 그룹 오적용 차단, 실제 타입에 해당하는 필수 선택 유지, 캐시·관리자 한도를 검사했다. 실제 Chromium에서 명판 가림이 인접 사진 내용을 보존하고 명판 내부를 가리는지 및 기존 업로드·생성·복구를 검사했다. 실제 동작특성시험 원본 한 장을 작업용 크기로 변환해 가림 전후도 대조했다. 이전 가림 범위에 포함되던 계측기 인접 픽셀들이 새 처리에서 보존되는 것을 확인했다. 이 검사는 이미지 전처리 확인이며 AI 작업명 정답 검사가 아니다.

**이 수정 후 실제 비전 API의 동작특성시험 정답률은 아직 측정하지 않았다.** 이전 추천을 새로고침하는 것만으로 재추론하지 않는다. 앱에서 내용이 미확정인 사진에 AI 추천을 다시 요청해야 새 기준을 사용한다. 실제 정답과 대조한 평가 없이 이 수정을 정확도 개선 수치로 보고하지 않는다.
