- 실제 브라우저 렌더링·모바일 실기기·서버 프로세스 강제 종료 시험·외부 배포는 수행하지 않았다. 테스트는 복구 함수 및 worker 경로를 검증하며 실제 운영 장애 내구성을 보증하지 않는다.
