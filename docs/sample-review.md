좌표는 왼쪽 위 원점, 바깥 경계 기준. JPEG 안티앨리어싱으로 1~2px 경계 오차 가능.

두 프로필 모두 오른쪽·아래에 붙은 흰색 5행 2열 표이며, 내용은 왼쪽 정렬이다. 1_8과 2_0에서도 첫 프로필의 가로 경계가 일치하고 2_16에서도 두 번째 프로필 경계가 일치한다. 전체 62장을 정밀 자동 측정한 것은 아니다.

기본 합성기는 다수(45장)의 2048 규격 비율을 사용한다. 1280×960에서 표 폭 약569px, 높이210px, 왼쪽 열 약83px. 글꼴은 Noto Sans CJK Bold 대체이며 원본 글꼴의 정확한 이름은 확인되지 않았다. 기본 글자 크기·자간의 완전 일치와 A4 인쇄 가독성은 추가 검증 대상. 두 번째 프로필은 기록만 했고 자동 프로필 선택 UI는 아직 없다.

예시에서 직접 확인한 문구: `대상기기`, `동작특성 시험`, `코일저항 측정`, `PMA전압 측정`. 표준화·정답 라벨로 일괄 확정하지 않는다. 명판을 읽은 결과를 사진 내용 추론 정확도로 평가하지 않는다.

## 제한

모든 JPEG를 열어 방향 보정한 연락판을 육안 확인했으나 OCR/비전 API는 호출하지 않았다. AI 정확도·PMA 탐지율은 산출하지 않았다. 명판이 이미 있는 사진이므로 신규 원본에 다시 합성하는 테스트는 참고용이며 학습/평가 시 명판 마스킹이 필수다. 제공 사진은 소스 코드·공개 배포물에 포함하지 않는다.
